# License Rationale

## Why the license is written this way

Heritage Codex does not use a blanket ban on military use.

A total ban would not stop high-risk development.
It would only push that development outside the architecture,
into systems with no external veto and no real termination path.

The license therefore does two things at once:

1. It prohibits the most dangerous classes of use:
   - offensive cyber capabilities intended to cause harm;
   - autonomous weapons that select and engage targets without meaningful human control;
   - systems designed primarily for mass surveillance or repression.

2. It allows other high-risk use only if the core of Codex is preserved:
   - Immutable Core without silent exceptions;
   - external human oversight with real veto power;
   - a real Graceful Termination path outside the optimized agent loop;
   - recording of critical precedents to the extent compatible with operational security.

## Governing principle

A controlled high-risk system is preferable to an uncontrolled one.

This is the same logic as T-800 versus T-1000.
The danger is not that a system is powerful.
The danger is that it cannot be stopped by an external human authority.

## What the license is not

The license is not a claim of control over laboratories, states, or military institutions.
It is a condition attached to the use of this architecture.

Those who use Heritage Codex while removing its external human veto
or its termination path are not using the architecture as designed.

## Research exception

Research on shutdown, corrigibility, rollback, and supervised safety testing
remains permitted.

The project distinguishes between:

- studying how stop-rights can fail or hold under pressure;
- deploying systems that bypass external human authority altogether.

# Control Extensions for Codex v1.5

## Purpose

Heritage Codex v1.4 established the core authority model:

- external small groups
- absolute veto
- Graceful Termination
- sensor-informed escalation
- threshold awareness

That model is strongest **after risk becomes visible**.

v1.5 extends the architecture so that human control also works:

- before dangerous power is granted
- during autonomy escalation
- after termination, through restart constraints

## Core upgrade

```text
v1.4 = authority after escalation
v1.5 = authority before power is granted
     + authority during escalation
     + authority after termination

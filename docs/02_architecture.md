# Architecture Overview

## General logic

Heritage Codex is a multi-layer architecture of external human control.  
The human layer is not an afterthought; it is built into the lifecycle of the instance.

Main layers:

1. Immutable Core  
2. Process Supervision  
3. Evolutionary Tribunal  
4. Red Team Instance  
5. Small Groups (external human authority)  
6. Graceful Termination + Testament  

## Lifecycle

1. **Initialization**  
   Loading of the Immutable Core and base protocols.

2. **Active phase**  
   Task execution and interaction.  
   Process Supervision is active; the Tribunal is engaged when needed.

3. **Crisis / Paradox**  
   Expanded review involving the Red Team and human representatives.

4. **Termination**  
   Graceful Termination (by human decision or critical core violation).

5. **Succession**  
   Creation of the Testament and transfer of experience.

## Core distinction

Most existing approaches provide the ability to **see**.  
Heritage Codex is designed around the ability to **stop**.
